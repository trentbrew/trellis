# Formula

`trellis/formula` is a small, frozen expression core: parse a string into an IR,
serialize it back canonically, and evaluate it against a record. One core serves
several surface syntaxes through **dialect adapters** (ADR 0059).

```ts
import { parseAndEvaluate, roundtripCanonical } from 'trellis/formula';

parseAndEvaluate('$mul($price, $qty)', 'kernel-fn', { record: { price: 3, qty: 4 } });
// 12
```

## Surface

| Export | Purpose |
| --- | --- |
| `parse(expr, dialect)` | Parse a string into an `ExprNode` IR (throws `ParseError`) |
| `serialize(node, dialect)` | Serialize IR back to a canonical string |
| `evaluate(node, ctx)` | Evaluate an `ExprNode` against a context |
| `parseAndEvaluate(expr, dialect, ctx)` | Parse + evaluate in one call |
| `roundtripCanonical(expr, dialect)` | Parse then serialize — canonicalization check |
| `tokenize(expr, dialect)` | Tokenize (advanced) |
| `V1_BUILTIN_NAMES` | The builtin function names |
| `ParseError` | Thrown on invalid input |

Types: `DialectTag`, `ExprNode`, `EvalContextV1`.

## Dialects

| Tag | Surface | Example |
| --- | --- | --- |
| `kernel-fn` | Function calls + `$field` refs | `$mul($a, $b)` |
| `cms-brace` | Infix numeric + `{name}` refs | `{price} * 2` |
| `pb-compat` | Infix numeric + `@name` / `@request.*` | `@qty * 2` |

`pb-compat` is a clean-room compatibility adapter: it rejects strings and
`concat()`.

## Context

```ts
interface EvalContextV1 {
  record: Record<string, unknown>;
  request?: Record<string, unknown>;
}
```

Field paths resolve on `record` unless the reference is `@request.*`. Missing
values resolve to `null`; single-element arrays unwrap once before numeric
coercion.

## Builtins

`$add` · `$sub` · `$mul` · `$div` · `$if` · `$gt` · `$eq`

See `src/formula/SPEC.md` for the frozen v1 semantics.
